        不会取 Cookie？点开看 30 秒教程
        
    
          
  1. 最省事：点「浏览器登录获取」→ 弹出的浏览器里扫码登录 → 自动抓取并保存，登录一次长期复用。
    2. 
          
  2. 手动方式：浏览器打开并登录 douyin.com → F12 → Network → 任意请求右键 Copy as cURL → 整段粘贴到左侧框 → 「解析并保存」。
    3. 
          
  3. 插件方式：装 Cookie-Editor → Export → JSON → 粘贴 → 「解析并保存」。
    4. 
          
  4. 保存后会自动生成 cookies/<平台>_cookies.txt，链接检索与 yt-dlp 下载会自动复用同一份，无需重复配置。
    5. 
          
  5. ⚠ Cookie 等同账号凭据，仅存在你本机 cookies/ 目录（已自动加 .gitignore），切勿外传。
    6. 
          
  6. 🔑 快手特别注意：快手 Web 搜索接口强制要求请求签名(__NS_sig3)，纯 HTTP 粘贴 Cookie 也会被风控拦截（探活会显示 result=2 / 400002）。关键词搜索请勾选「浏览器搜索」，或改用「分享链接解析」通道最稳。
    7. 
          
  7. 🔗 任意网站：在「🌐 自定义网站」框输入网址 → 点「打开网址并登录」→ 浏览器打开该站，登录后自动抓取并保存（落盘为 custom_<域名>，下载/分享链接解析可自动复用）。
